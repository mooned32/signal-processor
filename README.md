# Signal Processor

Десктопное приложение для анализа сигналов и шумов на базе PyQt6.

## Важное примечание по физическим расчетам ($U_c$)
При расчете полезного сигнала используется формула:
$$U_{c\_i} = \sqrt{U_{сш\_i}^2 - U_{ш\_i}^2}$$

В реальных физических экспериментах из-за статистических флуктуаций уровень шума $U_{ш}$ в отдельной точке может кратковременно превысить смесь сигнала и шума $U_{сш}$.
Чтобы предотвратить появление комплексных чисел и ошибок извлечения корня из отрицательного значения, в коде реализовано защитное ограничение:
- Если $(U_{сш\_i}^2 - U_{ш\_i}^2) \le 0$, значение $U_{c\_i}$ принудительно принимается равным **`0.0`**.
